Portfolio Website Project
This repository contains the source code for a modern, responsive personal portfolio. This project was built as a collaborative effort to showcase professional skills, projects, and experience in a clean, high-performance format.

## Tech Stack
Frontend: ReactJS / HTML5 & CSS3

Styling: Tailwind CSS (for responsive utility-first design)

Icons: Lucide-React / FontAwesome

Deployment: Vercel / Netlify

## Key Features
Responsive Design: Fully optimized for mobile, tablet, and desktop views.

Project Showcase: A dynamic gallery featuring live links and GitHub repositories for key projects.

Experience Timeline: A structured layout detailing professional growth and academic milestones.

Contact Integration: A functional contact form or direct links to professional socials (LinkedIn, GitHub).

Dark/Light Mode: (Optional) Support for user-preferred color schemes.

## Getting Started
To get a local copy up and running, follow these simple steps:

Clone the repo

Bash
git clone https://github.com/Debarghyasg/Friend-s-Portfolio.git
Install dependencies

Bash
npm install
Run the development server

Bash
npm run dev
Build for production

Bash
npm run build
